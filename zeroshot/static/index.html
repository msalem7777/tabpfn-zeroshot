03 / PROPAGATE UNCERTAINTY

Many plausible datasets.
One combined prediction.

Each draw samples literature parameters, generates context labels, and predicts test rows with fixed-weight TabPFN. The final prediction averages these TabPFN distributions.

Run settings

The proposed defaults use a normal distribution for uncertain coefficients, Gaussian residuals for linear models and Bernoulli outcomes for binary models. Each evidence model must specify and justify these choices. Mixture weights, unit conversions and population-transfer assumptions are also explicit.

Building predictions uses the displayed settings and source-model assumptions. Missing quantities are not silently set to zero. Unsupported equations or rows are skipped with reasons. Intervals remain conditional on the source evidence.

How uncertainty is combined

Average each model’s prediction spread, then add the disagreement between model means. Increasing the number of draws improves the calculation; it does not remove uncertainty about the real outcome.

Runs are sequential to limit GPU memory. Cancellation takes effect after the current network or inference call returns. TabPFN may require model access or license acceptance on first use.
